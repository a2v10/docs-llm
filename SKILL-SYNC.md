### 2.2 `references/sql-rules.md` — дописать отсутствующие системные наборы

Скилл знает только `$System`. В доке теперь описаны ещё два, оба с рабочими примерами:

- **`$Aliases`** — подстановка имён полей, вычисляемых во время выполнения. Имя поля в SQL —
  литерал; `$Aliases` передаёт настоящее имя *значением*. Псевдонимы принято начинать с `~`,
  чтобы они не совпали с реальным именем поля (подстановка идёт по **всем** именам последующих
  наборов). Должен быть возвращён **до** первого использования.
  Главное применение — `MapObject` с ключами, зависящими от данных.
- **`$Defaults`** *(только NET.Core)* — значения по умолчанию для незагруженных элементов корня
  модели; можно возвращать безусловно. Поддерживает `RefId` и `Utc`, строки локализуются,
  `null` игнорируется.

Плюс требования к порядку наборов: `$Aliases` — до первого использования псевдонимов, `$System`
— после всех элементов, на которые ссылается (на практике последним), `$Defaults` — где угодно.

## 3. Ошибки скилла, подтверждённые автором платформы

Проверено у Александра Кухтина в явном виде — не догадки.

| Место | Сейчас в скилле | Правильно |
|---|---|---|
| `references/sql-rules.md`, Column markers | `!UtcDate` — «Convert the column UTC→local on model load» | **Маркер называется `!Utc`.** `!UtcDate` не существует. Описание поведения верное |

`!RowNumber` в скилле — **верно**, оставить. Это маркер результирующего набора, нужен для
правильной перенумерации строк на клиенте. Не путать с колонкой TVP: в табличном типе это
обычное поле с обычным именем (например `RowNo`), никакого маркера там нет.

## 4. Открытые вопросы — НЕ править, пока не решены

- **Тип отчёта `stimulsoft` устарел** и будет выпилен из docs-llm (вместе с `report`,
  `variables`, `.mrt`). В скилле его и нет — там `xml | json | pdf | xlsx`. Осталось
  подтвердить, что `pdf`/`xlsx` — действительно текущий список, а не домысел.
- **`permissions` в `model.json`** описаны в скилле (`view | edit | delete | apply | create |
  unapply | flag64 | flag128 | flag256`, биты `view=1, edit=2, delete=4, apply=8`), но
  отсутствуют и в docs-llm, и в украинской справке. Источник этих значений неизвестен —
  проверить по реализации, прежде чем на них опираться.
- **Формат `clrType`**: скилл `clr-type:My.Type;assembly=MyAssembly`, docs-llm
  `"MyApp.X, MyApp"`. Кто прав — не выяснено.
- **`!Json`, `!Expanded`** есть только в скилле; в справке не встречаются.

Полный реестр расхождений (с раскладкой по уровню доказательности) — `DISCREPANCIES.md` в корне
docs-llm.
