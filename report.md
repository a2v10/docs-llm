# Xaml Reports

> Printed forms the platform builds itself from a template — the template language, its expressions, the Excel-drawn workbook variant, and how a report is shown and printed on a form.

- [Reports Overview](https://docs-llm.a2v10.com/report/overview.md): What a report template is, how it is declared in model.json, where its data comes from, the Code section
- [Report Expressions and Bindings](https://docs-llm.a2v10.com/report/bind.md): How values reach the document — scope, Bind versus braces, DataType and Format, functions, quoting
- [Report Elements](https://docs-llm.a2v10.com/report/elements.md): Flow elements — the base element, Length and Thickness, Page, Column, Inlined, Text, List, Line, Checkbox
- [Report Table](https://docs-llm.a2v10.com/report/table.md): Table, TableRow, TableCell, TableColumn — repeating rows, merged cells, the ready-made table styles
- [Report Images and Codes](https://docs-llm.a2v10.com/report/images.md): Image, QrCode, Barcode and the page watermark — bytes from the model or a file of the application
- [Report Workbook](https://docs-llm.a2v10.com/report/workbook.md): The template drawn in Excel — cells, named ranges, row and column sizes, the page footer
- [Viewing and Printing Reports](https://docs-llm.a2v10.com/report/view.md): PdfReportViewer on a form, and the print and download buttons beside it
