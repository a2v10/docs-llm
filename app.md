# Application Configuration

> Application-wide configuration for A2v10 — files and special folders that apply to the whole application rather than a single endpoint.

- [menu.json](https://docs-llm.a2v10.com/app/menu.md): Application-level navigation file — the single root menu tree, with titles, icons, and endpoint links
- [_layout](https://docs-llm.a2v10.com/app/layout.md): Special folder attaching external scripts and stylesheets to the shell — `_scripts.html`, `_styles.html` (.NET Core)
